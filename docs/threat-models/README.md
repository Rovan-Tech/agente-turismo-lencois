# Threat models (STRIDE)

Funcionalidade crítica (endpoint, webhook, autenticação, dado pessoal, chamada a LLM) tem aqui um
modelo de ameaças **antes** do código (Manual V5 §2; `GOV-2`). Cada mitigação vira teste
automatizado (`SEC-7`). Crie com a skill `/threat-model <funcionalidade>` ou copie `modelo.md`.

Arquivo: `AAAA-MM-DD-<funcionalidade>.md`.
